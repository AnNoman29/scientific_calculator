# Scientific Calculator in C++

A menu-driven scientific calculator developed using C++ and VS Code.

## Features

- Addition, subtraction, multiplication and division
- Power, square root and cube root
- Trigonometric and inverse trigonometric functions
- Logarithm and natural logarithm
- Factorial, percentage and absolute value
- Degree and radian modes
- Height conversion: Feet/Inches and Centimeters
- Weight conversion: Kilograms and Pounds
- Land conversion: Shotok and Acre

## Requirements

- A C++ compiler such as GCC
- VS Code or any suitable code editor
- A terminal to run the program

## Compile

```bash
g++ scientific_calculator.cpp -o calculator
```

## Run on Windows

```powershell
.\calculator.exe
```

## Run on Linux or macOS

```bash
./calculator
```
